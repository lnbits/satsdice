# Sats Dice - [LNbits](https://lnbits.com) extension

LNURL-powered dice game. Players pay sats for a chance to win based on configurable odds. The game runs entirely through scannable QR codes.

## How it works

Create a dice game with your odds and payout multiplier. Players scan the LNURL QR code, pay the entry fee, and instantly find out if they won. Winners receive their payout automatically via LNURL-withdraw.

## Features

- Configurable win probability
- Custom payout multipliers
- LNURL-pay for entry
- Automatic payouts to winners

## Usage

1. Enable the extension in LNbits
2. Create a dice game with your odds and stakes
3. Share the QR code
4. Players scan, pay, and play
